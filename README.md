<h2> Modular Architecture Breakdown</h2>
<h3>1. Core Basics & Memory Allocation (`Basics/`)</h3>
<p>
Deep-dive tracking of primitive structures, strict data type transformations, system string mutations, and high-precision mathematical calculation boundaries.
</p>
<ul>
    <li><b>01_variables.js:</b> Scoping boundaries and primitive state declarations.</li>
    <li><b>02_datatypes.js:</b> Type analysis and deep understanding of memory architectures (Stack vs. Heap).</li>
    <li><b>03_strings.js:</b> Advanced text manipulation, templates literal structuring, and prototype methods.</li>
    <li><b>04_number-math.js:</b> Precision controls, explicit number castings, and dynamic randomized ranges.</li>

<h3>2. Dynamic Execution Engines (`ControlFlow/`)</h3>

Mastering high-intensity conditional logical gates, iterations, loops, and optimized data array filtering pipelines.

<h3>4. Data Schemas & Object Mapping (`Objects/`)</h3>

<h2> Technical Challenges & Real-World Learnings</h2>
<h3>The Switch to State-Driven Interfaces</h3>
<p>
The core challenge wasn't writing separate lines of logic, but figuring out how data models inside memory blocks (like an Array of Objects) translate smoothly into user interaction elements on a live webpage.
</p>
<ul>
    <li>
        <b>The Solution:</b>
        I focused heavily on building a reset-and-apply architectural pipeline using functional array loops. By cleaning the DOM trace buffer (via class modifications) before applying active user selections, data loops and memory leaks are completely prevented.
    </li>
</ul>
<br>
<h3>Persistent Session Traps</h3>
<p>
Normal JavaScript global variables instantly flash and reset during system reloads, making browser data highly volatile.
</p>
<ul>
    <li>
        <b>The Solution:</b>
        I mastered serialization mechanics using JSON stringify workflows to turn live system objects into plain secure text streams. These are cached in browser local storage and reconstructed safely back into functional logic instances via data parsing layers.
    </li>
</ul>
